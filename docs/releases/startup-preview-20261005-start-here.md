# 智绘学途：下载后如何测试

这是待测试的预览安装包，不是正式稳定版，也不代表技术冻结。

## 选对文件
- Intel Mac：darwin-amd64.tar.gz（当前作者机器已观察入口、安装、教师登录）。
- Apple Silicon Mac：darwin-arm64.tar.gz（已构建，尚无对应实机验收）。
- Windows 11 x64：windows-amd64.zip（已构建，尚无Windows实机验收）。
- 不要选择 GitHub 自动提供的 Source code；它不是此安装包。

## 第一次启动
1. 安装并打开Docker Desktop，等待运行就绪。Windows使用WSL2/Linux容器。
2. 将安装包完整解压到独立文件夹，不覆盖现有SmartSketch源码目录。保留bin、清单、Compose与入口。
3. Mac双击start-macos.command；Windows双击start-windows.cmd。
4. 在浏览器向导填写向量API地址、Key、精确模型名称和输出维度（默认1024不适用于所有模型）；设置首位教师用户名和至少8位密码。无需手动建.env或设置数据库密码。
5. 保存配置并启动，首次会从公开GHCR下载固定摘要的前后端镜像及Neo4j。待“打开软件”可用后点击，用刚设置的教师账号登录。
6. 在“模型API设置”配置个人生成模型；上传自己的课程文件进行测试。实际抽取/问答会消耗你所选供应商的API额度。安装向导本身只校验格式，不验证供应商连接或额度。

这是独立新安装；旧开发环境配置和课程不会自动导入。保持Docker运行；关闭向导/终端不等于停止服务。不要删除命名卷或改动原密钥。

## 当前已知边界
- 完整integration门禁通过；使用合成数据和本机假供应商，不代表真实供应商或跨平台验收。
- 真实Mac Intel包首次安装及教师登录已观察；独立系统浏览器重开与“打开软件”按钮交接已观察。
- 自动重复入口验收整体失败，定位未结束；另一次自然流程重开成功，不据此抹去自动失败。
- 停止按钮确认框的自动浏览器处理超时，最终UI停止未签收。
- Finder双击、下载后的Gatekeeper、Mac ARM及Windows实机仍未验收。程序未做平台代码签名。遇系统拦截请保留提示，不要全局关闭安全保护。
- 这是Release草稿，不是公开发布；源码Tag绑定尚待处理。

问题反馈请提供固定错误阶段或脱敏截图，不要发送API Key、密码、.env、数据库或备份。SHA256SUMS供核对附件完整性。

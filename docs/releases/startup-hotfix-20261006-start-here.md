## Intel Mac 测试步骤

1. 在此草稿的 Assets 下载文件名含 hotfix-20261006 和 darwin-amd64 的 .tar.gz，勿下载 Source code。
2. 保持 Docker Desktop 开启，关闭旧启动器终端窗口。关闭窗口不会停止数据库服务。
3. 完整解压新包到另一文件夹，核对 SHA256SUMS，双击新目录的 start-macos.command。不要沿用旧目录里的入口。
4. 原 API 配置、安装ID、数据与账户保留，不需要重填向量 Key、不需要删 .env 或重装数据库。
5. 若页面显示初始化中断，请填原教师用户名（大小写均可）及首次密码，点击“启动 / 重试”。已有账号继续使用首次密码，这不是密码重置。
6. 等待就绪，点击“打开软件”，用首次账号密码登录。若失败，导出新脱敏诊断；不要发送 .env、密码、Key 或备份。

新安装用户仍按首次向导填写向量 API、教师账号及端口。

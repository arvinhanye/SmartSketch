# ADR-007：学习材料生成纳入范围，定位为加分项

- **日期**：2026-09-22
- **背景**：参考方案 §6.4.7（4）把「学习材料生成」明确标为**加分项**，表 3.2 系统功能清单把它列为学生端能力，§8 方案亮点也声称具备，表 6.8 还有对应提示词 `gen_study_material`。但 `docs/product.md` 的 MVP 六项能力里没有它，「非目标」清单（3D、跨课程融合、SSO、移动端、计费）里**也没有它**——既未纳入，也未排除。继续沉默会导致两种后果之一：没人做而方案亮点自相矛盾，或某个 Agent 看到 `prompts/MANIFEST.md` 里有这一项就顺手实现，挤占已经逾期的主链路工期。产品负责人已决定做。
- **决定**：
  1. **纳入范围，定位为加分项**：必得分项（资料导入 → 图谱构建 → 教师审核 → 图谱浏览 → 学习导航 → 可信问答）全部达标后才投入资源。
  2. **能力边界照方案原文**：为**学习路径中的知识点按需**生成通俗讲解、示例与 **3 道练习题（附答案解析）**；结果**缓存**，避免重复调用模型；**可由教师审核**。
  3. 生成内容同样受 [ADR-003](ADR-003-answer-source-citation.md) 约束：必须基于课程原文并给出来源；资料不足时返回 `NOT_COVERED`，**不得用模型常识编练习题**。这是加分项里最容易出问题的一条——讲解和习题比问答更容易让模型自由发挥。
  4. 提示词 `gen_study_material` 状态保持 `TODO`，按 `prompts/README.md` 的版本—改动—效果流程推进，与其他提示词同等对待。
  5. **优先级低于 M1 全部任务**。M0 已逾期 3 天的前提下，不得因加分项挤占主链路。
- **后果**：
  - `docs/product.md` 的 MVP 范围表增加一行并标注「加分项」；学生主流程增加一步。
  - 新增 **M1-07**。它的前置是「学习路径推荐」，而**该能力目前在任务板上没有任何任务**——学生端（图谱浏览、学习导航、可信问答）整体缺任务，属于 D-06，已更新该条。
  - 需要「缓存」与「教师审核生成内容」两项附带能力，数据模型影响在 M1-07 建任务时定稿。
  - `prompts/MANIFEST.md`「与仓库现状的两处出入」第 2 条作废。
  - 方案 §6.4.7（3）「目标导向路径」同样标为加分项，本 ADR **不涉及**；它要不要做仍未决定，已并入 D-06。

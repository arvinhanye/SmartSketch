## 3 模块调用与数据流

```text
Vue 页面 → composables / Pinia → REST/SSE client
                            ↓
FastAPI 路由 → 权限与 DTO → 领域服务 → 仓储 → SQLite / Neo4j
                               ↑
                     独立 worker（任务领取/租约）
                               ↓
                  解析器 → 抽取/融合 → 模型适配器
```

推荐业务闭环（不覆盖未决 ADR）：

1. 上传流经格式/大小校验，文件临时保存；同事务写资料记录与 queued 任务；失败清理临时文件，补偿失败留下记录。
2. worker 持久领取任务；解析正文并留下原文定位；清洗与分块保留映射。缓存键至少含课程/内容哈希/解析器/提示词/模型版本，块身份另含文档和位置，避免重复正文把来源串错。
3. 先抽实体、融合名称与候选，再组装小节实体表抽关系；实体缺失、跨课程端点、自环、重复边在模型输出边界处理。每块失败可重试，部分失败的整体状态与发布条件需定义。
4. 自动构图生成待审核草稿；人工编辑与融合都不能绕过手改锁、端点作用域、DAG。并发 A→B 与 B→A 需要在同一课程的写入序列/事务中校验，单独先查后写存在竞争。
5. 发布时先生成可校验的版本快照及对应图/向量，校验成功后最后切换发布指针；SQLite 与 Neo4j 没有此项目已实现的跨库原子事务，必须显式补偿。失败时学生保留上个完整版本。
6. 图谱读取、学习推荐、问答在请求开始绑定同一个已发布 version_id；所有后续查询、引用解析和缓存使用同一版本，不在请求途中随最新指针漂移。
7. 引用校验前的流式文字只能是“待校验内容”；校验失败清除或替换该内容，并返回明确终态，防止界面留下无依据的完整回答。只校验引用编号存在不足以证明每条结论被支持，还需评测结论与证据的一致性。

## 5 学习路径与 AI 细节

可学集合：`k ∉ M 且 predecessors(k) ⊆ M`。无直接前置的节点可学。该规则不证明用户手动标记的 M 在传递前置上闭合；用户跳过先修后标记掌握的语义需单独决定。

S2 评分：`0.35 × 解锁度 + 0.25 × 重要度 + 0.20 × 章节顺序 + 0.20 × 易学度`。解锁度应区分“后继总数”和“学完这个点后真的满足全部前置的新增可学点数”；后者更贴合现有措辞。归一化、中心度、并列键在实现前定稿。每条理由从分量生成，例如给出解锁节点 ID 列表，不凭空生成数字。

8 项提示词：`extract_entities`、`extract_entities_gleaning`、`extract_relations`、`judge_duplicate`、`summarize_definition`、`rewrite_query`、`answer_with_context`、`gen_study_material`。每项独立任务，配固定输入/期望结构/失败样例。模型输出合法 JSON 不等于正确知识，人工标注集评估另设任务。

阈值与成本：相似度阈值、检索门槛需标注集；模型名称、预算等配置只写入 `docs/integrations.md` 与 `.env.example`。本报告不重复 S2 价格估算，不宣称现价已验证；真正接入时核对供应商官方资料。

## 6 架构审查结论与优先级

详细文件行号及触发条件见 [首轮 Claude 审查](reviews/codex-claude-initial-2026-09-22.md)。

1. **P1 契约真源冲突**：YAML-first 与 Pydantic-first 同时标作唯一来源，ADR-004 还被两个分支赋予不同含义。先裁决，复用已有路径/字段成果，避免重写两套。
2. **P1 契约门禁失效**：缺 PyYAML 仍以 0 退出，现场验证确实 SKIP。门禁需区分 PASS / SKIP / FAIL，并在实现里程碑启用强制检查。
3. **P1 来源硬约束仅为文字**：answered 可声明空引用，页码/章节都可省略，ChatEvent 无必填字段。补结构约束与负例测试后再生成客户端。
4. **P2 状态/接口前缀漂移**：同一分支规格缺 persisting/cancelled；两个分支 `/api/` 与 `/api/v1/` 不同。统一事件状态、wire 枚举大小写及取消语义。
5. **架构高风险未定**：快照/向量版本、跨库补偿、幂等缓存、DAG 并发、取消持久化、流式引用撤回。属于设计缺口，不伪装成现有运行时 bug。
6. **计划缺口**：main 仅 M0/M1 粗粒度任务，没有学生端闭环任务；分支 S-06 编号重复。本次原子清单补齐主线与可选项，并与原任务映射。

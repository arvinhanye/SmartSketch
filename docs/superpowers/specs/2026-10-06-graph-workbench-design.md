## 1. 目标与边界

**目标**：把图谱页做成清晰、可信、克制的课程知识工作台，并在节点多（约 100 个）时仍可读。

**保持不变（业务）**：学生掌握状态与「标记 → 推荐刷新」；服务端确认前不显示成功；推荐与先修路径；来源可定位；`not_covered` 与服务错误分开；关系类型仅 `CONTAINS`、`PREREQUISITE`、`RELATED_TO`、`EXAMPLE_OF` 且先修方向清楚；课程隔离；教师审核与发布规则。

**不做**：新业务流程、新接口字段、新依赖、3D、跨课程融合、自动出题、撤销/重做（现无对应业务）、批量框选/套索、保存「场景」。

**接口与契约**：无变更。所有新增交互（预览、局部视图、筛选、目录、小地图）在前端本地完成。

## 3. 视觉 tokens

- 应用外壳用 `--ss-*`，图谱工作区用 `--gw-*`，放在新文件 `src/frontend/src/styles/tokens.css`，**不改现有 `--color-*`**；其他页面推广前保持原样。

### 3.4 画布元素

- **节点**：圆形，普通直径 36px，选中/重点最多 48px，边框 1.5px `#606A7B`；类型填充 concept `#DDE5F3`、theorem `#E5DEF4`、formula `#F6E6CD`、method `#D8EAE6`、example `#E8EAD8`。
- **类型标记**：填充与画布对比仅 1.12–1.20，不能只靠颜色；节点内放单字标记（概/理/式/法/例），图例与详情带完整类型名。
- **掌握状态**：`unknown` 显示明确文字「未学习」（详情、预览卡、列表），不加角标；`learning` 角标 ◐；`mastered` 角标 ✓。颜色之外有文字或图形。
- **关系线**：`CONTAINS` `#727A89` 实线 1.5px；`PREREQUISITE` `#5145CD` 实线 2px + 明确目标箭头；`RELATED_TO` `#4C7480` 虚线 1.5px（无箭头）；`EXAMPLE_OF` `#906638` 点线 1.5px。线型与颜色共同编码，选中路径 2.5px，箭头方向遵守契约。语义标签仅在选中/预览的相邻关系上显示，带不透明浅色底。
- **节点标签**：13px/500，放节点下方，最多两行并省略，完整名称经 tooltip 与详情提供；标签带与画布同色的不透明底，避免关系线从文字中间穿过。
- **选中**：2.5px 靛紫外环、标签加粗；一阶邻居突出。非相关内容的淡化强度见 3.4a（标准档：降填充饱和度 `#ECEEF2`、边框 `#7F8695`、标签 `#545967`；强档：Obsidian 式）。**都不使用整体 opacity**。
- **屏幕尺寸下限**（缩小时防止比例失衡）：标签靠放大字号保持约 13px，节点、线、箭头不能随缩放缩成 7px 的点和 0.3px 的发丝。因此设下限（不是缩小标签，也不是降透明度）：节点直径 ≥14px、线宽 ≥1px、箭头 ≥6px、选中外环 ≥2px；放大系数按档位量化（节点 0.25 步、线宽 0.5 步），避免滚轮缩放时每帧重绘；角标与类型字随节点同比放大。缩放 ≥ 约 0.4 时下限不起作用，尺寸与原设计一致。
- 不使用渐变、玻璃模糊、霓虹、发光（G6 内置 `active` 边状态自带 halo，必须显式关闭）、循环背景动画。

- **搜索命中 / 章节定位**：靛紫外环 + 标签加粗并改靛紫色（`#5145CD` 对画布 6.2:1）；**不使用淡紫色底块**（预览第一版用过，用户反馈不要）。

### 3.4a 非相关内容的淡化（已决：悬停强淡化，预览标准淡化）

**依据**：Obsidian 的图谱视图把强淡化绑在**鼠标悬停**上，悬停节点及其连接保持清楚、其余退后，鼠标移开即恢复；全局图和局部图都有，点击是打开笔记，没有持久选中（官方文档与社区讨论；其余节点的具体透明度与文字是否淡化我没有验证）。

| 状态 | 持续性 | 淡化强度 | 说明 |
| --- | --- | --- | --- |
| **悬停节点** | 瞬时，鼠标移开 60ms 后恢复；触屏无此效果 | **强（Obsidian 式）**：悬停节点与其直接相邻保持清楚、相关边加粗；其余节点退成近画布色小点（填充 `#F0F1F4`、边框 `#C9CED8` 1px），标签与掌握角标隐去，其余关系线变浅变细（`#D3D7E0` 1px） | 状态叠加顺序：基础状态在前、悬停状态在后，悬停优先；被预览/选中的节点即使与悬停节点无关也保留外环，用户不会丢掉自己的焦点 |
| **预览 / 选中** | 持久，直到点空白、Esc、✕ | **标准**：非相关节点填充降到 `#ECEEF2`，边框 `#7F8695`，标签 `#545967` 保留；关系线保持原样 | 文字 ≥4.5:1、边框 ≥3:1，全部达标 |
| **只看相邻** | 持久，用户主动开启 | 隐藏非相邻节点（不是淡化），提示条可恢复 | 想要持久的强效果用它 |

- 都**不使用整体 opacity**；强效果靠「换成近底色 + 隐藏标签」，因此画面上没有低对比的文字残留。
- 对比度例外：悬停强淡化期间，非相关节点边框与关系线约 1.6:1，低于原定的 3:1。因为它是**瞬时**状态、这些元素此时只是背景上下文，且仍可通过列表、搜索、章节跳转、预览找到并操作，所以记为有意例外；持久状态（预览、选中、筛选）不受影响，仍满足 ≥3:1。
- 悬停淡化只服务指针用户，**没有键盘对应物**：画布本身不可键盘到达，等价路径（列表、搜索、章节跳转）里没有悬停语义，需要的信息都在预览卡与详情里。
- 预览设置里保留两个开关用于对比：「悬停强淡化」（默认开）和「预览（持久）时的淡化」（默认标准，可切到强）。正式实现不保留这两个开关。
- 实现注意：悬停进出只刷新元素状态（`setElementState`），不重绘数据；只依赖节点的 `pointerleave` 在快速移动时不可靠，需要同时监听画布空白处的 `pointermove`、边的 `pointerenter` 与画布容器的 `pointerleave` 作为兜底。

### 3.5 对比度（已用页面实际渲染色实测，预览阶段）

- 文字最低 5.30:1（辅助文字），要求 ≥4.5:1；控件边界最低 3.95:1，要求 ≥3:1；焦点与图形对象 ≥3:1。
- 装饰分隔线 `#35363F` 对 `#18191D` 仅 1.46:1，仅用于装饰，不承担识别。
- 实测发现并修复：可点击卡片误用装饰线色（1.39:1）→ 改用控件边界色 `#747A87`。
- **未做**：G6 画布内像素色采样、传送到 `body` 的 tooltip/菜单、全部交互状态的逐项检查，实施阶段补。

## 4. 节点多时的对策（五层）

背景：预览中约 96 个节点时「适应画布」缩放为 0.2（G6 允许的下限），标签不可读。借鉴 Bloom「不让用户同时面对整张图」的思路。

| 层 | 做法 | 依据与说明 | 批次 |
| --- | --- | --- | --- |
| 1 标签分级（含避让浮层） | 缩小时标签在屏幕上保持约 13px（按缩放分档放大），并按优先级贪心排布：在屏幕坐标里估算占位，不与已放置的重叠才显示；被预览/选中/搜索命中/推荐的节点永远显示 | **预览实测后改为自研**：G6 自带 `auto-adapt-label` 在 96 节点下仍漏掉重叠，`fix-element-size` 的缩放行为不可控。优先级：预览/选中 > 搜索命中 > 推荐 > 选中节点的邻居 > 契约的 `importance`（缺省按度数估算）。G6 节点用布尔属性 `label` 开关标签（`labelVisibility` 无效）；字号放大时必须同步 `labelLineHeight` 与 `labelWordWrapWidth`。适配层 `G6NodeData` 需新增 `importance`。**标签还必须避开浮层**：把工具栏、搜索栏、图例、小地图、底部折叠条、预览卡、提示条的屏幕包围盒作为障碍物传给排布函数（预览里用 `data-obstacle` 标注，正式实现改为显式的障碍物注册），落在障碍物下的标签不显示（预览/选中的节点也一样）；浮层出现、消失、展开收起时重新排布。章节与搜索命中的标签只是高优先级，**不再强制保留**（只有预览/选中强制），仍要避让 | P0，**预览已验证** |
| 2 小地图 | 右下角缩略图 + 视口框，带地图开关与缩放、适应画布控件；缩略图只画节点，已掌握绿、学习中琥珀、当前高亮靛紫、其余石板灰，同时是学习进度总览 | G6 自带 `minimap` 插件（外部容器 + 自定义 `shape` 克隆主形状重新着色，隐藏的节点不画）；销毁前要延后一点，否则插件的延迟渲染会在销毁后报错。装饰性，键盘等价路径是搜索、章节跳转、列表 | P0，**预览已验证** |
| 3 只看相邻 | 预览卡里的开关：只显示该节点及 1 或 2 跳邻居，其余隐藏；顶部提示条「只看「X」的相邻知识，已隐藏 N 个」，可切 1 跳/2 跳、恢复全部；清除预览不会取消局部视图 | 借鉴 Obsidian 局部图；由用户主动开启，隐藏状态可见、可恢复，不降透明度，对比度不受影响。显示集 = 局部视图 ∩ 类型筛选，列表与底部计数同步 | P0，**预览已验证** |
| 4 图例即筛选 | 图例显示关系与类型的计数，可按类隐藏；章节菜单显示每章数量与已掌握数；被隐藏的类别显示「已隐藏」，图例内「恢复全部」同时恢复关系与类型 | 借鉴 Bloom 的 Legend panel；现有按关系筛选保留；计数取整张图，不随筛选变化 | P0，**预览已验证** |
| 5 章节分区 | 用淡色轮廓框出每章节点区域 | G6 有 `bubble-sets`、`hull` 插件，但与 dagre 布局配合需先做小实验，**不承诺** | 第二批 |

跨章先修边（长弧线）是版面最乱的来源：未选中时保持 1px，选中节点后相关边加粗到 2.5px 并显示关系名；不降透明度。

**章节跳转**（已实现于预览）：画布左上「章节」菜单；选择后保持当前缩放（不低于可读缩放），把该章最靠上的节点放到画布上部，该章节点高亮，出现可取消的「已定位」标签；列表视图下滚动到该章。

### 4.1 画布布局（已决：采用章节分区 + 紧凑间距，用户确认 2026-10-07）

- **现状的两个问题**：① 四类关系全部参与布局，跨章长线和「例题挂在远处」把画布拉成 5:1 的长条（96 节点 9042×1792，适应一屏缩放 0.10，没有一章能放进一屏）；② `antv-dagre` 的间距是「节点尺寸 + 3×nodesep / 2×ranksep」，现用参数实际是 204/256，过于宽松。
- **建议**：采用**章节分区布局 + 紧凑间距**（nodesep 28、ranksep 57）：层级只由 PREREQUISITE 与 CONTAINS 决定；RELATED_TO、EXAMPLE_OF 照常画但不拉扯位置，无层级边的节点作为卫星挨着所关联的节点；每章单独布局，各章按课程顺序排成分区；缺章节信息的节点归入「未归章」分区。不删除、不隐藏任何关系。
- **收益**（合成数据，视口 884×732）：96 节点适应一屏缩放 0.10 → 0.35（先修稀疏 0.43，无先修 0.46），每章都能放进一屏（8/8），章内平均连线缩短约 80%；30 节点 0.31 → 0.70。
- **代价与处理**：跨章连线仍长、交叉数不降（稀疏数据上增加）。处理放在 D：未选中时跨章线更细更浅，预览/悬停/章节聚焦时加粗；章节分区用外框标出。
- **独立可先上**：仅把间距改紧凑，零语义风险，缩放 0.10 → 0.15。
- **验证要求**：布局是纯函数 `computeLayout(nodes, edges, mode, chapterOrder, options)` + `measure(...)`，正式实现保留并加测试（节点最小间距、先修方向、孤立节点不成长条、章节顺序）；需要用真实课程数据再验证；`chapter_id` 缺失、章节很大（>20 个节点）、全孤立等边界要覆盖。

### 4.2 章节聚焦（D，预览已验证）

- **整章范围适应**：章节跳转把本章节点整体放进视口（按包围盒算缩放 0.2–1.2，居中到未被浮层占用的区域），不再聚焦一个点；「适应画布」与局部视图（只看相邻）同样只按**可见**节点计算范围。8 章 × 3 种关系构成（完整 / 先修稀疏 / 无先修）全部 12/12 个节点在视野内，且没有节点被浮层压住。
- **章节外框**：用 G6 `hull` 插件圈出定位章节（淡紫底 `#EEEBFB`、靛紫 1.5px 虚线边、padding 34），画在节点后面（`zIndex: -1`）；不要移除插件，首次添加后只更新成员与可见性；渲染之后添加/更新要主动调用 `drawHull()`。
- **淡化其他章节**：章节聚焦且没有预览/选中时，非本章节点按标准档淡化；本章节点靠靛紫外环和加粗靛紫标签突出（无淡紫色块）。
- **跨章关系线弱化**：未被强调时画 1px（只变细、不变浅，颜色对比度仍 ≥3:1）；涉及预览/选中/章节聚焦时恢复正常粗细。
- **图例**：章节聚焦时自动收起（软障碍：标签避让它，镜头适应不因它缩小），清除定位后恢复；用户手动开合后不再自动恢复。
- **标签强制规则**：只有被预览/选中的节点强制显示；推荐项、搜索命中、章节成员只是高优先级、仍要避让。强制必须用布尔值判断，不能用累加分数的阈值（章节成员 +950 再加推荐项 +300 会越线）。标签宽度用真实字体量，排布合并窗口内有新事件时窗口结束后要再算一次。
- 量化：章节聚焦时总览标签重叠 8–14 对 → 0 对；章节跳转后视野内章节节点 2/12 → 12/12。

## 8. 状态与可访问性

- **页面状态**：加载（骨架 900ms 低幅循环，固定占位）、空（「已发布的图谱中暂无知识点」）、未发布（「课程尚未发布知识图谱」）、错误（`role="alert"`，说明已发布图谱没有改变，带重试）；`not_covered` 与服务错误在问答页保持分开显示，本文不改动。
- **键盘**：所有控件可 Tab 到达，焦点环 2px、offset 2px（暗色 `#B1ACFF`，图谱浅色 `#5145CD`）；Esc 依次关闭菜单、导航抽屉、详情抽屉、取消预览。
- **屏幕阅读器**：预览卡 `aria-live="polite"`；画布 `role="img"` 带节点与关系数量；图例按钮名称写明「显示中/已隐藏，点击切换」。
- **不仅靠颜色**：类型（单字 + 图例）、掌握（文字/角标）、关系（线型 + 箭头）、隐藏状态（文字）。
- **减少动效**（`prefers-reduced-motion: reduce`）：关闭位移、缩放、循环骨架和镜头动画，保留静态状态与不超过 100ms 的淡入；动效不得延迟请求、SSE 或错误显示。

## 9. 动效

统一 easing `cubic-bezier(0.2, 0, 0, 1)`，只动画 transform 与 opacity，不用 `transition: all`。

| 场景 | 规则 |
| --- | --- |
| 按钮 / 导航 hover | 120ms，背景与边框变化 |
| 按钮按下 | 80ms，主按钮 `scale(0.98)` |
| 页面首次呈现 | 180ms，opacity 0→1 + translateY(4px)→0，只用于整块内容 |
| 覆盖抽屉 | 220ms，translateX(−16px)→0 并淡入；遮罩 160ms |
| 菜单 / tooltip / 预览卡 | 120–140ms 淡入，位移 ≤2px；tooltip 延迟 300ms |
| 节点 hover / 选中 | 120–160ms 轮廓与强调变化；节点不漂移、不弹跳 |
| 适应画布 / 定位 / 章节跳转 | 240ms，使用 G6 5.1.1 镜头 API；普通点击不自动居中 |
| toast | 淡入 160ms，默认 3000ms；重要错误保留页面内提示 |

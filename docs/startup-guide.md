# 双击启动与本机安装

本功能处于开发验收，尚未发布含真实镜像摘要的正式下载包。当前开发环境继续使用原 scripts/start.sh；不要把源码目录当作已发布安装包。

## 正式包的使用流程（发行验收后生效）

1. 安装并打开 Docker Desktop；Windows 11 x64 使用 WSL2/Linux 容器。Mac 按芯片下载对应包。
2. 从可信发行渠道获取完整包并核对 SHA256SUMS，解压到本机目录。
3. Mac 双击 start-macos.command；Windows 双击 start-windows.cmd。保持 Docker 运行，不要求安装 Python、Node 或 Go。
4. 浏览器向导配置向量服务的地址、模型、维度与 Key，并设置首位教师账号。随机数据库口令、JWT 与个人模型凭据加密根密钥由启动器生成。
5. 等待全部服务、索引与代理检查通过再打开软件。教师/学生在网站内配置各自的生成模型 API；学生沿用注册流程。

这是新独立安装，不包含旧开发环境课程。配置只做格式检查，未验证供应商连接或额度，不自动调用收费 API。

## 生命周期

- 配置保存在 Mac ~/Library/Application Support/SmartSketch 或 Windows %LOCALAPPDATA%\SmartSketch；数据在安装 ID 的命名卷。
- 再次双击复用原安装；关闭终端/控制页不会停止 Docker 中的业务服务。
- 仅“停止服务”停止本安装，保留卷和原密钥；不会终止占用端口的其他进程。
- 缺 Docker/配置损坏时，按提示处理后重试；不自动降级到演示模式。
- 已保存配置后端口冲突，在控制页面“更换网站端口”输入1024–65535的空闲端口，明确确认只停止本安装后保存，再点击启动；课程、账号和密钥保留，不关闭其他程序。
- 不要删 .env 或手工更换 MODEL_CREDENTIAL_KEY / Neo4j 口令；丢失时需要原配置备份。

## 升级与恢复保护

没有自动更新。版本不一致时启动器停在升级保护，不执行迁移。

受控核心提供先确认停机、租约检查、整组卷归档、配置/发行清单与摘要核对；恢复只写暂存卷。恢复先完成暂存服务的探测，再要求第二次确认切换，原卷保留。只降级镜像、只还原 SQLite 或重新生成密钥都不构成完整恢复。

备份包含密钥与课程资料，应留在本机私有目录，不上传 GitHub 或当作诊断附件。真实Docker合成安装的停启、双安装隔离、整组备份/重复恢复测试结果见本轮报告；这不是用户真实业务库恢复的签收。真实业务数据恢复及三平台正式包操作尚待验收，不能把合成场景当作生产恢复保证。任何真实升级/恢复请先保留原安装和完整快照，并等待对应版本的验收说明。

## 平台边界

源码跨编译与单元测试不等同于 Mac ARM / Windows 实机通过。正式下载地址、匿名镜像拉取、中文路径双击、Docker 未运行与中断恢复均以平台验收报告为准。

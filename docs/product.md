# 产品定义

## 产品目标

智绘学途将分散的课程教材、教案、课件和习题转化为可审核的课程知识图谱，并以图谱为依据提供学习导航与可追溯问答。系统优先解决“知识点零散、学习顺序不清、通用问答缺乏课程依据、教师构图成本高”四个问题。

## 用户与主流程

### 教师

1. 创建课程并上传 PDF、DOCX、TXT 或 Markdown 资料。
2. 查看异步处理状态：解析、抽取、融合、校验、待审核。
3. 审核节点/关系，修正低置信度项；新增前置关系时系统检测环。
4. 发布图谱版本，供学生使用；后续版本可回退。

### 学生

1. 进入已发布课程并浏览 2D 知识图谱。
2. 搜索、筛选关系、查看节点定义和来源。
3. 标记已掌握知识点，获得下一步学习建议、先修依赖和推荐理由。
4. 提问并查看答案、涉及知识点和原文出处；资料不足时显示“课程资料未覆盖”。

## MVP 范围与成功条件

| 能力 | MVP 验收目标 |
| --- | --- |
| 资料导入 | 支持 PDF、DOCX、TXT、Markdown；每份资料有任务状态 |
| 图谱构建 | 单章抽取知识点 ≥20 个与四类教学关系，按课程隔离；前置关系无环 |
| 教师审核 | 可编辑节点/关系、处理低置信度项、发布版本 |
| 图谱浏览 | 2D 缩放、拖拽、搜索、详情、关系图例与筛选；并提供与图谱联动的卡片/列表视图 |
| 学习导航 | 学生标记掌握状态后获得下一步推荐与理由；指定目标知识点可生成完整路径并在图谱上高亮编号 |
| 学习材料 | 为路径中的知识点按需生成通俗讲解、示例与 3 道练习题（附解析），可缓存并由教师审核 |
| 可信问答 | 结合图谱与原文检索；回答带来源，未覆盖时明确返回状态 |
| 多课程 | 至少并行维护两门不同学科课程，互不可见、互不干扰 |
| 性能 | 单章（约 2 万字）解析+抽取 ≤60 秒；问答完整响应 ≤15 秒；无 GPU 普通电脑可运行 |

## 非目标

本轮不实现 3D 图谱、跨课程知识融合、生产单点登录、原生移动端、支付计费或开放给公众的内容市场。

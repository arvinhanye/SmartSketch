### FIX-R01 P2：收到无 usage 的响应会把实际 LLM 调用计为零

- **目标提交 / 位置**：`1012b6f`，`docs/integrations.md:138`、`:153-154`、`:172`；同样规则写入 `docs/decisions.md` ADR-011 修订 2。
- **触发条件**：供应商返回成功响应或错误响应，但不带 `usage`；预写记录随后被回写为 `ok` / `error`。规格只在“未收到响应、仍为 sent”时采用估算，对已回写但缺 usage 的记录明确记 0。
- **影响**：这类真实发出的 LLM 请求从任务及每日预算中消失；重复调用可绕过软上限，尤其在备用、修复或部分兼容供应商不稳定返回 usage 时。`call_id` 修好了去重，却未保证计量下界。
- **最小修复**：响应缺少可解析 usage 时保留/采用预写估算值并标记估算，不按 0 计；补“成功响应无 usage”“错误响应无 usage”两条预算回归用例。

## 风险与已知限制

- 撤销靠反向操作，不是事务回滚：别人同时改图时这一步可能失效（会说明并移除）。
- 撤销“删除关系”得到的是一条新的人工关系，原编号、来源片段与审核状态不恢复。
- 知识点保存前某个字段没有值（如没填重要度）时，接口无法把它改回“没有”，这次保存不进撤销记录。
- 撤销 / 重做的提示是全站共用的右下角弹窗，会暂时盖住画布右下角的缩放按钮（4.5 秒后自动收起）。
- 撤销记录只在页面内存里，刷新页面或换课程后清空。

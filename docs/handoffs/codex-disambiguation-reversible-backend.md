## 配置与运行

`DISAMBIGUATION_AUTO_MERGE_ENABLED=false` 默认关闭。显式开启时新任务同时使用提及身份及语义工厂；分析开关仍可单独使用。既有 prepared 计划进入 persisting 后固定消费，不因随后关闭开关改写身份。详细预算见 [集成配置](../integrations.md)。向量仅在 `EMBEDDING_MODE=online` 接入，不把 fake/demo 向量当作领域语义；普通向量失败标记缺失通道，审计/鉴权失败不静默吞掉。

本地维护入口（所有值从实际列表取）：

```sh

PYTHONPATH=src/backend .venv/bin/python scripts/fusion_undo.py --course C --actor U --plan P --group G --expected-revision N
# 上一命令只预览；确认要执行时追加 --apply
```

服务端验证当前课程教师身份。入口不运行迁移、不调用模型、不读取个人模型凭据。默认输出计划/组/覆盖及冲突 ID，不倾倒课程正文。

## 存储与回退

迁移 021 增加 `courses.draft_storage_version`、`fusion_plans`、`fusion_undos`；默认仍为旧 `draft`。物理 `draftgen_*` 只能作为逻辑 draft 的存储位置，不能伪装发布版本给学生读取，也不参与发布孤儿版本清扫。草稿读取、编辑、审核、生成、失败清理和发布统一解析指针。离线 reembed 将 draftgen_*（含保留的撤销副本）识别为可变草稿，重算向量而非跳过为发布孤儿。

本轮仅在临时 SQLite 与独立 Neo4j 容器应用迁移，没有迁移/清理开发课程。保留旧副本和不可变前后快照，存储增长暂未做自动回收。回退旧代码前需要停写、备份，将当前有效副本迁回旧 `draft` 并校验一致；不能只删列/表。迁移回滚脚本检测活跃投影指针并拒绝不安全回退。

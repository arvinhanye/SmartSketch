## 1. 已交付行为

### 1.1 语义裁决与领域知识

新增 `SemanticResolver`，输入同课程的两个知识点、定义及可定位材料，输出 `SAME / DIFFERENT / UNCERTAIN`，同时独立记录 `complete / failed / deferred`。允许模型使用已有领域知识判断“散列表/哈希表”等同义，输出 `material / model_knowledge / mixed` 作为判断依据类别；材料引用只是定位用法，不能冒充外部权威证明。

拟 SAME 的结果必须经过第二次独立差异复核，复核不接收第一次答案。明确 DIFFERENT 和 UNCERTAIN 不增加这次复核。任一次输出不合法，共享最多一次格式修复；每对最多三次逻辑调用。底层策略可能进行物理重试及备用切换，仍逐次记账和执行预算检查。

双侧来源 ID 必须属于各自输入；单侧引用、结构不合法、SAME 同时列出差异、截断输出，都不能得到有效 SAME。两次语义判断不一致时保留 UNCERTAIN。服务只返回分析结果，不创建合并定义，不写图。

### 1.2 提及身份

显式开启新模式时，块检查点保存 `entity_identity_version=2`。任务、文档修订、块、引用位置、名称、类型、定义、证据共同决定提及身份；不再仅按名称提前丢掉同名不同义项。gleaning 同样保留不同义项，关系抽取收到定义和证据。

引用在块内重复出现时，未经校验的首个匹配不能视为唯一位置：

- 模型给出 `evidence_start` 时，必须是合法整数且精确匹配原文，否则丢弃该候选。
- 未给出偏移且有多个匹配时，标记 `evidence_ambiguous=true`。抽取项序号只用于保持独立，不代表真实文本位置，也不证明实际有几个不同概念。
- 有这种来源的候选对不进入模型同义裁决，记为 `deferred/ambiguous_evidence`。后续精确定位或有界重抽是下一批工作；本批没有把它转成人工语义争议。

旧检查点仍按 v1 读取。接管任务根据已有成功块固定身份模式，开启或关闭配置不会改变已生成关系的端点。旧模式仍使用原名称归组；本批没有迁移旧任务、课程或图数据。

### 1.3 生成阶段接入

在小节关系抽取前进行有界分析，结果与成功小节检查点一起保存，包括版本、输入摘要、逐对结论、完成/未完成数量。复用现有共享线程池、预算、鉴权及租约协议；默认并发仍为 8，保留实体块优先调度。

本批采用小节内按稳定顺序枚举、到预算即停止的分析方式，默认每小节 32 对；未检查的候选对明确进入 `unprocessed_pairs`。这不是完整方案中的跨章节混合召回，不能据此报告召回达标。

技术失败不会伪装成 UNCERTAIN；普通模型错误不抹掉可继续抽取的关系结果。鉴权失败、熔断、记录存储失败仍走任务级异常。新模式在每次物理请求前重查凭据、取消及有效租约，覆盖重试、备用切换和格式修复；取消或失租后不写成功检查点。

### 1.4 长输入保护与指标

语义请求按完整 UTF-8 字节数、包装开销和输出预留检查预算；超限记 `deferred/input_budget`，不裁掉限定语后强判。它是保守工程上限，**不是模型有效上下文窗口或零幻觉保证**。实体/关系长窗口切分、跨窗口覆盖、模型/提示词压力评测仍待后续实施。

新增离线 `evaluation/evaluate_disambiguation.py`，读取带独立标签的 JSON，报告 SAME 判定精度、同义检出召回、分析覆盖和技术未处理数。失败/延后不会从召回分母消失；没有 SAME 输出时精度为空，不虚报 100%。脚本不调用模型，也不测量合并簇准确率或教师审核用时。

## 3. 独立审查与处置

完成一次只读独立代码审查，发现 2 个 Important、2 个 Minor，无 Critical。重要问题均先加入能复现的失败回归，再修复：

| 问题 | 处置与证据 |
| --- | --- |
| guard 只在逻辑调用前执行，L1 重试/备用切换可绕过撤销检查 | 回调下沉到策略每次物理请求预写之前。重试、普通备用、流式备用三种反例均由失败转通过；被 guard 拒绝不新增调用记录 |
| 引用重复时总取首次位置，导致提及误折叠 | 显式偏移原文校验、重复引用歧义标记及独立序号。真实抽取器四种反例由失败转通过；含歧义来源的裁决零模型调用 |
| Minor：`input_digest` 未纳入输出预算 | 延至缓存接入前修复；当前没有用该摘要复用结果的消费者，禁止将它直接当作跨配置缓存键 |
| Minor：部分 `ModelError` 的分析失败记录丢失调用元数据 | 延至分析审计完善时修复；`decision.model_calls` 不是精确计费数据，成本/物理请求数以 SQLite `model_calls` 为准 |

两项非阻断 Minor 保留在待办，不用“审查全绿”描述本轮。以下是明确的阶段取舍：

1. 关系与分析维持原子小节检查点。关系最终失败或进程在落盘前崩溃，会丢失这次未提交分析并可能重做；本批未引入独立决策缓存。
2. 分析与关系共享任务预算，没有关系专用预留。分析可能消耗预算导致关系部分失败，应按现有部分失败协议报告，不声称完整生成。
3. 没有实测真实模型的语义精度、提示注入抵抗力或有效上下文窗口。fake 仅证明调度、校验、状态与存储行为。
4. 自动合并、组内一致性、图校验、跨任务贡献版本、撤销仍按完整设计推进，不以这次交付替代。

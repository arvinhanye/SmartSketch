## 问题清单

### P0：影响答辩演示或真实使用

1. **学生问答要自己配大模型 API Key**（正式模式）。`api/chat.py:98` 在未配置时返回 409 `MODEL_CONFIG_REQUIRED`；学生的「模型 API 设置」页向学生暴露了服务地址、API Key、刷新模型列表、关闭模型思考等开发者级选项（截图 13）。真实课堂里学生不会去买 API。
   - **已决（用户，2026-11-02）**：保持每人各自配置（沿用 ADR-080），不改为教师共享。因此本项不改权限模型，只降低学生的配置门槛：设置页默认选中供应商预设（`useModelDiscovery.ts` 已有 `MODEL_PROVIDERS`），把「刷新模型列表」「关闭模型思考」收进高级选项；问答页未配置时直接给出去设置的入口和一句话说明；答辩时提前为演示学生账号配好。
2. **学生无法自助入课**：注册后只看到「请把用户名告诉任课教师」（截图 08）；教师端只能逐个输入用户名添加（截图 07），没有邀请码或批量导入。
3. **示例课程图谱质量差，不能用于答辩**：演示模型（规则抽取）产出「栈和队列都」「也可以改」「凡」「代价」「性质 3.1（合法出栈序列判定」等残句节点；64 个点里只有 1 条前置关系，学习路径几乎退化；课程简介写着「由 scripts/import-demo.py 创建，可安全重跑」（截图 02、10）。答辩需要一份由真实模型抽取、经人工审核后发布的课程数据，并能离线预置。
4. **学生图谱首屏空白约 3–5 秒**，没有加载态（截图 09）。答辩现场会显得像卡死了。

### P1：流程断点与摩擦

5. 资料处理完成（「待审核」）后，资料页没有「去审核」入口，也没有「抽到 N 个知识点」的摘要；顶部提示仍停在「正在处理」（截图 04）。
6. 选文件后还要再点「开始上传」，多了一步。
7. 新建课程后停在列表页，没有直接进入新课程或资料上传页。
8. 课程概览页底部重复列出「全部课程」，还带「新建课程」按钮，和概览的职责不符（截图 03）。
9. 刷新页面后问答记录丢失（截图 12）：历史只保存在前端内存（`useChat.ts:76` 的 `course.chatHistory`）。
10. 学生概览页没有学习进度（已掌握 x / 64），进度只在图谱页左栏。
11. 左侧功能栏只有图标没有文字，教师端 6 个图标需要逐个试。
12. 问答页空态没有示例问题，学生不知道该问什么。

### P2：文案与细节

13. 推荐理由是算法原话：「解锁度 1.0000」「难度未标注，按中性值 0.5 计，易学度 0.5000」。应改为「学会它可以解锁 1 个新知识点」这类说法。
14. 登录页写「密码」，注册页写「口令」，用词不统一。
15. 出处里的文件名换行断裂（`ch3- stack- queue.md>`，截图 10 左栏）；问答引用编号从 [2] 开始，没有 [1]。
16. 「涉及的知识点」一次列 30 个，信息过载。
17. 成员页显示「暂无学生成员」，下面的列表里却有教师一行。
18. 发布按钮没有二次确认，也没有说明发布后学生会看到什么。

## 「AI 感」来源（视觉与文案）

- 配色：近黑外壳（`--ss-bg: #101114`）+ 靛紫主色（`#5b5bd6` / `#5145cd`，在 `.vue`/`.css` 中出现 101 次，含变量引用）。这是最常见的 AI 产品模板配色。
- 登录页：深色底、发光紫色插画、「开始你的学途」小标题 + 渐变强调字，加上顶栏的「AIGC 课程知识图谱智能构建与学习导航」。
- 文案：「课程助教」「已回答」「解锁度」这类系统腔，以及数值化的推荐理由。
- 布局：图标侧栏 + 大圆角白卡片 + 浅灰底，缺少教学产品的辨识度（如教材式排版、章节结构、衬线标题）。

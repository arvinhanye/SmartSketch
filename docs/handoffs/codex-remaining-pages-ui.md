# 剩余页面 UI 改版交接

## 范围与基线

用户在课程与模型设置改版后要求「其他几个页面 UI 也改一下」。沿用 PR #322 `55b19d0` 基线、本地分支 `codex/courses-model-settings-ui` 及前两页未提交改动，不新增工作副本。此次完成资料、审核与版本发布、成员、课程问答、教师图谱的视觉统一；登录/注册仅基础色板与控件对齐。未提交、推送、部署或修改业务数据。

## 实现

- 全部课程路由使用暗色顶栏/导航，面包屑显示课程名与当前页；教师导航使用资料、审核、成员的独立图标。
- 管理页面复用 PageSheet/PageHeader；资料页为上传卡、限制说明、模型配置提示与资料处理行列表，原进度、取消/重连/重试/删除确认不变。
- 成员表单移至列表上方；表格保留语义与操作，手机按带字段标签的卡片排列；原移除确认及课程内权限不变。
- 审核页以分类导航与队列内容并置，版本发布放在独立底部分区；所有原条目、合并确认、环路提示、发布/回滚语义和钩子保留。
- 问答使用暗色消息流、输入卡与来源栏；手机来源排列在对话下方；保留 SSE、停止/重试、引用和未覆盖/错误分离。暗色代码块实测对比度回归覆盖，不能沿用旧的浅底代码样式。
- 教师图谱使用顶部筛选、左侧编辑面板、右侧增强画布，手机上下堆叠。完整草稿章节位置计算后显示筛选子集，保持点击选择、键盘下拉、编辑与离开守卫。原状态/锁定/来源编码保留，教师 tooltip 显示草稿状态。
- 布局异常时退回基础模式；复审发现恢复时 lifecycle 未更新，已补监听 enhanced 的重建及回归。手机绘图区原被 scoped 增强样式清零，浏览器测量 clientHeight=0，已加教师专用最小高度覆盖。
- 认证页暗色表单与品牌外壳对齐；装饰图谱、减少动效、窄屏隐藏、登录/注册校验保持原样。

## 与完整路线图的边界

本轮完成现有页面的 UI 改版，不声称 PR #322 全路线图收口：未新增批量审核、关系交互状态机、全站旧样式删除或新的 API；原 GraphToolbar 与键盘下拉保留。审核展示分类与所有条目，而非改造成需要额外选择状态的单条详情工作流。真实课程上传→发布→学生问答的生产数据主线、全量 integration 与人工无障碍审计未执行。学生图谱沿用已有样板，不借此次升级修改学习业务逻辑。

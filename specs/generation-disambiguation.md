# 生成消歧实施规格：DISAMBIG-BE-02

依据用户 2026-11-11 的实施授权和[完整设计](../docs/superpowers/specs/2026-11-11-knowledge-disambiguation-design.md)。本文件细化第二批后端的存储与运行协议；不改变前端代码，不默认开启自动合并。

## 1. 审计与召回

- 输入摘要包含模型、提示词、输入/输出预算、候选策略版本和完整内容/来源。模型技术错误在裁决服务内形成失败结果，保留已发生的逻辑调用数、已响应模型及提示词摘要；鉴权、熔断、计费存储故障仍向任务层传播。物理调用和成本以 `model_calls` 为准。
- 同课程名称/别名索引、词项检索、同空间真实向量近邻候选取并集。相似度只用于召回，不直接批准合并；fake 向量不参加生产语义召回。按节点 top-k 和全局候选预算限制开销，记录截断/缺失通道，不能称为全量语义检查。
- 保留全部原始提及。局部分析和全局分析复用同一召回与裁决规则；来源含定位歧义、完整输入超预算时保持独立并记录技术覆盖缺口。

## 2. 映射和图校验

- 只有成功且经过差异复核的 SAME 可成为映射依据。任何组中任意两成员均须有当前输入对应的 SAME；缺项、DIFFERENT、UNCERTAIN、技术失败均禁止该组合并，禁止传递闭包自动扩张。跨任务已合并节点从不可变计划恢复全部原始成员卡，验证新增的所有交叉对；缺少原始成员或预算不足保持独立，不把规范节点当成一个新单成员。
- 教师锁定、人工内容、教师已审核项（approved/rejected）不自动吸收；不跨课程。已有“不是重复”对和“确认保留”节点也是硬约束；审核记录进入头快照及最终 SQL 校验，不能被模型覆盖。规范节点优先保留已有节点和其有据定义，别名及所有来源去重保留，不额外生成定义。
- 在完整当前草稿及新任务原始候选上模拟映射。合并造成任意知识关系自环、先修环或来源/端点缺失时拒绝该组；不通过删除或降级关系掩盖合并错误。未受映射影响的 RELATED_TO 方向与 ID 原样保留；人工/已审核关系若需改接或碰撞合并，拒绝该组。原始关系自身成环仍按现行 ADR-009 处理，与合并诱发环分开。
- 映射版本和输入摘要进入最终检查点；持久化必须消费指定结果。关系依据保留原始端点，本批采用保守的末端映射重接，遇到需要重新解释的关系保持独立，不猜测关系指向。

## 3. 可见性和存储

- SQLite 追加 `fusion_plans`（课程/任务、快照修订、有效任务集合、原始/结果图、决策、组、状态）及独立撤销记录；课程保存当前草稿存储版本，默认 `draft`。
- Neo4j 逻辑作用域仍为 `draft`，独立 `storage_version_id` 只决定物理副本位置；所有草稿读、审核、编辑、发布、任务持久化使用同一 SQLite 指针和 V。学生不能通过物理草稿 ID 绕过草稿权限，发布清扫不删除草稿副本；离线 reembed 将保留的物理草稿按可变草稿重新向量化，不当成发布孤儿或复用旧向量。
- 自动合并写入新 `draftgen_…` 副本，不能改旧可见副本。原始输入、映射、合并前后快照不可变；当前生效副本仍支持既有教师编辑，后续自动合并再创建新副本。
- 生成推理在课程写锁之外。取得课程锁后核对草稿修订、V、当前物理副本和审核拒绝/保留记录。过期计划不生效，保留原始候选并记录 `stale_snapshot`，不把过期结论用于审核过滤。
- Neo4j 写入后，在现有 T6 SQLite 围栏中同时切换指针、激活计划及完成任务。图提交成功但 SQLite 未提交时，新副本不可见；重试幂等。旧副本和审计快照保留，不在本批自动清除。
- 无合并组时仍保存分析结果，沿用当前草稿副本写入原始候选。兼容 v1 任务；已存在的 v2 任务继续保持身份。
- 删除从未贡献图谱的资料时，先执行现有任务阶段、有效贡献和 `cleanup_pending` 检查；同课程、同资料任务的 `prepared/skipped` 且未应用、无撤销审计的计划可随删除事务清理。已提交、已应用或有撤销审计的计划禁止清理，返回既有 `contributed` 不可删除原因；不改迁移外键或删除其他资料、课程的记录。

## 4. 撤销一项自动合并

- 撤销按课程、计划、组 ID 和预期草稿修订操作；不撤销整个生成任务，也不改变 awaiting_review/completed 状态。
- 基于保存的原始图和其余有效映射生成逆向差异；把差异应用到当前草稿，保留后来增加的无关任务节点、关系及教师修改。只恢复被撤销合并影响的节点、别名、来源与边。
- 受影响内容在合并后被教师修改、锁定、删除，或存在依赖该组的后续映射/新关系时，返回包含受影响 ID 和原因的冲突预览，不覆盖新内容。没有冲突时在新副本中执行逆向差异并原子切换指针，追加撤销记录；重复撤销幂等。
- 撤销是一次新的草稿写入：实际恢复或修改的节点修订号必须大于其当前和合并前的修订号，包括重新出现的被吸收节点；不能恢复旧并发令牌。其他节点及其修订号原样保留，使独立组可按任意顺序连续撤销。冲突比较仍包含修订号，教师“修改后改回”不能因内容相同而绕过检查。
- 发布快照不变。撤销后的草稿仍须正常发布，学生才会看到变化。
- 本批提供后端服务和受控本地维护入口；公开 HTTP/前端交互另行同步契约，不修改 Claude 正在修复的页面或生成客户端。

## 5. 验收

覆盖：输出预算变化摘要失效、模型第二次调用失败仍有审计；别名/词项/向量通道并集及同空间校验；A=B/B=C 不能未经 A=C 验证形成一组；锁定/跨课/来源歧义；自环与间接先修环；失败副本不可见；T6 指针原子性；过期计划；跨任务已有节点合并；撤销保留后来无关贡献；教师编辑/依赖冲突；重复撤销；发布只读有效投影且历史版本不变；关闭开关旧流程通过。真实模型准确率、候选召回率和审核用时不得由 fake 测试代替。

迁移/回退：使用既有迁移锁和备份协议，只在隔离测试数据库验证。关闭自动执行停止尚未准备的全局分析，已有 v2 身份和进入 persisting 的固定计划保留；回退旧代码前必须先把有效草稿副本迁回兼容的 `draft` 并验证一致，不能仅删除指针或迁移表。迁回或清理真实数据需独立操作，不在本轮自动执行。

## 6. 运行入口与覆盖报告

新开关及预算见 `docs/integrations.md`；自动开关同时启用提及身份和语义裁决工厂。v1 检查点保持兼容，不重新解释已丢失的义项。全局输入包含输出预算、模型/提示词、头快照、完整材料与召回版本；相同摘要重用已保存计划，无额外推理。

`PYTHONPATH=src/backend .venv/bin/python scripts/fusion_undo.py --course C --actor U` 列出计划、合并组、覆盖信息与草稿修订。追加 `--plan P --group G --expected-revision N` 只预览，追加 `--apply` 执行撤销。要求当前课程教师身份，不读取个人模型凭据、不调用模型、不运行迁移。冲突退出码 2。所有标识符取自列表结果，不猜测。

缺真实向量、候选截断、输入/语料预算或裁决未完成都会记录覆盖缺口；明确不同、无法判断与技术失败不混为一类。审核页新状态及语义队列过滤尚未接入，本批不改变旧审核 DTO；不能宣称人工审核减量指标已验收。

全局覆盖分母：`total_pairs` / `unprocessed_pairs` 按不同可见组之间的原始成员交叉对计数，历史组内已验证的对不重复计入；`recall.total_possible_pairs` 是可见规范节点对数，两者不得混用。`deferred_pairs` 记录保护、原始成员缺失或交叉对预算不足。审核页接入时应同时区分召回覆盖与语义裁决覆盖。

## 7. DISAMBIG-BE-03：审核与公开撤销契约

本节承接以上“另行同步”的 HTTP 阶段。现有 `/review` 和 `/review/actions` 路径与三栏结构保留。读取不调用模型，不改变图、任务或审核记录。

- 最新可见任务的已提交计划，在课程修订等于分析头 + T6 的一次递增、有效任务集合等于分析头加本任务、物理草稿指针一致时可用于过滤。prepared/skipped、已撤销、草稿修订/有效集合变化均不得沿用结论；这是保守的课程级失效，后续可细化成节点级依赖校验，不能在本批猜测旧结论仍有效。
- 有效分析的默认疑似重复栏只列完成判断的 UNCERTAIN，以及完成 SAME 但因整组/图安全约束未合并的可见二元提案。DIFFERENT 和已自动合并项不列；技术失败、未召回和预算截断只计入未检查覆盖，不包装成语义未决。历史合并组须聚合其原始成员交叉对：有缺项不产生语义结论，存在 DIFFERENT 不把该组当作同义提案。教师“不是重复”、已拒绝节点继续排除。
- 没有有效分析时保留原有名称候选以兼容既有课程，但明确 `queue_mode=legacy`、`status=not_analyzed/stale`，不得宣称已完成消歧。客户端必须同时查看覆盖状态，空队列不等于检查完整。该回退也让旧版审核页仍能继续人工处理。
- `ReviewQueue.disambiguation` 为兼容性新增可选字段，实际后端总会返回。新增 `GET /review/disambiguation` 返回同一摘要；nullable 计数表示当前分析不可用，不用零伪装完成。原始成员对的语义覆盖与可见节点对的召回覆盖分别给单位。队列条目可附 `analysis`（语义结果、未决原因、依据类型、差异、计划 ID）；相似度仅召回排序。
- 新增 `GET /review/merges`，按不透明游标返回已提交并实际应用的自动合并组历史（计划、任务、原始成员、规范节点、撤销状态）；不倾倒完整图快照或其他课程内容。历史已撤销状态不等于当前可撤销，必须调用预览校验。
- 新增 `POST /review/merges/{plan_id}/{group_id}/undo-preview` 与 `/undo`。均严格接收非负整数 `expected_revision`，拒绝额外字段、null、bool 与字符串数字。预览返回 ready/conflict/already_undone 及当前修订、受影响 ID、冲突；执行成功 undone/already_undone，相关冲突返回 409 `REVISION_CONFLICT`（details 为预览结果）。未知/非本课程/未应用计划与组为 404；权限、锁竞争、存储故障沿用既有 401/403/409/503。返回体不暴露物理草稿地址。重复执行已撤销组幂等，不改变任务终态与发布版本。
- 兼容 Claude `d102915` 的 getQueue/resolve 调用；只扩展接口与原因标签。现有手动合并预览语义和布局不在本批重写，自动历史/覆盖的完整展示由接口交接说明。

验收补充：DIFFERENT 过滤后 totals/游标/单项操作同源；语义候选不依赖词面命中；技术失败不冒充不确定；过期、未提交、失效任务、撤销后不隐藏；跨课程/非教师/重复撤销/写冲突；读取无模型调用；前端既有调用及类型可用。无新增数据库迁移。

## 8. DISAMBIG-BE-04：实体与关系抽取的有界窗口

- 新启用消歧的任务采用版本化窗口策略：完整渲染请求的 UTF-8 字节数 + 256 包装预留 + 4×输出 Token 上限，不得超过配置预算；这不是精确 tokenizer 或真实模型有效窗口承诺。每次物理调用前另做同一检查，包括 repair 与 gleaning，拒绝不完整输入，绝不裁掉实体定义/限定词来凑预算。
- 短输入保持单请求。长块按字符边界切分并重叠，保留原始块 ID、文档/修订/页码与原始证据偏移。仅完全相同的出现和内容去重；同名不同位置仍独立。窗口内部无法定位唯一出现时继续标记歧义，不伪造定位。
- 长小节的来源窗口按顺序覆盖全部字符、尽量保留邻接块上下文。实体表能整体放入则保留整体；不能时按实体对覆盖全部组合，所有源窗口都要核查。组合/窗口超过上限或单个完整实体对放不下时，不发无界请求、不截断实体表，记录技术缺口。窗口全覆盖只表示既定窗口全部处理，不等于跨任意距离的关系或语义全被模型识别。
- 实体/关系单元沿用原有成功/失败原子检查点：任一窗口失败不提交该单元的半份候选。检查点附窗口策略、内容/模型/提示词摘要、计划窗口、完成窗口和失败原因。没有新的一层重试；现有 L2 重试可能重做本单元早先窗口，调用成本仍由 model_calls 记账。
- 补漏按每轮实际已有实体表重新分窗，保留原始偏移与全部已得候选；主抽取与补漏累计共享窗口上限，另记补漏计划/完成数。主计划及必需补漏最少窗口可提前判定时，超限零调用；新增实体导致后续补漏超限时，在该轮调用前停止，整单元失败并记录已完成调用。小节关系预规划先于任何小节语义调用，确定超限不先消耗语义判断。
- 已有任务按首批检查点固定窗口策略；旧检查点无策略时沿旧路径接管，不把同一任务解释成混合算法。策略改变通过新任务生效。相同单元的来源和模型输入摘要包含窗口参数，来源/定义/预算变化不冒充同一计划。
- 全局准备绑定抽取检查点摘要；当前任务有失败块/小节或不完整窗口时，不执行自动合并，保留原始可用候选，报告 `extraction_incomplete` 与具体窗口原因。不得仅因剩余候选少而报告全部消歧完成。课程读接口仍不调用模型。
- 本批不提前局部合并实体，不实现局部拆分后的关系重抽；全局依然按 BE-02 保守映射。默认开关不变，无新增 HTTP 字段；新增迁移 022，为不可变检查点增加可空 JSON metadata，独立保存 window_policy/window_coverage，失败 result 仍为 NULL；窗口明细在检查点/计划审计，审核摘要通过 partial 与 reasons 提示技术缺口。
- 来源边界：窗口还原保留抽取器选中的证据位置。实体已有出现歧义保护；关系在同窗重复引文时仍沿用原抽取器的首匹配定位，不声明关系出现已唯一消歧，后续跟进 `DISAMBIG-FU-REL-01`。

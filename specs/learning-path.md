# 功能规格：学习路径推荐

- **状态**：DRAFT（桩，参数未定稿）
- **负责人**：产品 / 数据与 AI / 后端共同维护
- **关联任务**：尚无任务承接——学生端整体缺任务，见 **D-06**

## 用户故事

作为学生，我标记已掌握的知识点后，能拿到一份按优先级排序的「下一步学什么」列表；每条推荐都带一句我能核验的理由，而不是一个黑箱分数。

## 数据与规则

### 可学候选集

设学生已掌握集合为 `M`。知识点 `k` **可学**当且仅当：

- `k ∉ M`，且
- `k` 的**所有直接前置**（沿 `PREREQUISITE` 入边）都属于 `M`。

没有前置的知识点天然可学。判定只看直接前置，不做传递闭包——传递前置由 `M` 的既有内容隐含保证。

### 优先级评分

```text
score(k) = 0.35 × 解锁度   （学完 k 后可解锁的后续知识点数量，归一化）
         + 0.25 × 重要度   （重要度与图中心度加权）
         + 0.20 × 章节顺序 （越靠前越优先，贴合教学进度）
         + 0.20 × 易学度   （1 − 归一化难度）
```

权重可配置。四项分量必须各自可单独取出，否则推荐理由无法解释。

### 推荐理由

每条推荐附**一句可核验的理由**，指向具体数字或结构事实，例如「学完它可解锁 4 个知识点」「它是第 2 章的起点」。禁止输出「推荐学习」这类无信息量的话。理由由评分分量直接生成，不调用大模型——理由必须与排序口径一致，模型改写会引入不一致。

### 目标导向路径（加分项，是否做见 D-07）

学生选定目标知识点 `t` → 沿 `PREREQUISITE` 反向遍历取 `t` 的全部前置祖先 → 去掉已掌握的 → 用 Kahn 算法拓扑排序，同层内按上面的评分排序 → 在图谱上按步骤编号高亮。

### 隔离与依赖

- 所有查询按 `course_id` 隔离；已掌握集合中的知识点 id 必须属于同一课程。
- 依赖 `PREREQUISITE` 为 DAG（AGENTS.md §4、M1-04）。路径服务**不假设**上游已保证无环，见失败路径第 9 条。
- 学生只能对**已发布版本**计算路径（见 `specs/teacher-review-publish.md`）。

## 验收条件

### 成功路径

1. `M` 为空时，返回该课程全部无前置知识点，按 `score` 降序；每条带理由。
2. `M` 非空时，返回的每个 `k` 都满足「`k ∉ M` 且所有直接前置 ∈ `M`」；不满足的知识点不得出现。
3. **推荐顺序满足前置依赖**：对返回列表中任意两项 `a`、`b`，若 `a` 是 `b` 的前置，则 `a` 排在 `b` 之前。这是 `.claude/rules/testing.md` 点名要求的「学习路径排序」覆盖点。
4. 每条推荐的理由包含可核验的数字或结构事实，且与该条的评分分量一致。
5. 四项评分分量可单独取出并求和还原为 `score`。

### 边界路径

6. 该课程全部知识点都已掌握 → 返回**空列表加明确状态**（如「已全部掌握」），不是错误，也不是空 body。
7. 孤立知识点（无前置、无后继）→ 解锁度为 0，但仍进入候选集，不得被静默丢弃。
8. 评分并列 → 用**确定的次序**打破平局，保证同输入同输出（用哪个键见「待细化」）。
9. 权重被配置为全 0，或和不为 1 → 明确拒绝或归一化，二选一并有测试；不得静默按错误权重计算。
10. 候选集超过展示上限 → 分页或截断，且截断后仍满足第 3 条的顺序约束。

### 失败路径

11. 图谱中存在 `PREREQUISITE` 环（M1-04 理论上已拦住，但数据可能从导入或历史版本进来）→ 路径服务必须**检出并返回可解释错误**，指出环上的节点；**不得死循环、不得静默截断**。
12. 已掌握集合中含不属于该课程的知识点 id → 拒绝并指出具体 id，不得静默忽略。
13. 课程无已发布版本，或学生无权访问 → 按课程隔离规则拒绝，错误码可机读。
14. 图谱为空（课程刚建、尚未构图）→ 返回明确的「尚无图谱」状态，不是空列表（两者语义不同，前端提示不同）。

## 待细化

- **解锁度的归一化口径**：除以全课程最大解锁数，还是除以知识点总数？影响跨课程可比性。
- **重要度的「图中心度」用哪种**：度中心性、PageRank 还是介数中心性；与「重要度」本身如何加权。
- **难度字段的来源**：教师标注、模型推断，还是按章节位置推定。S2 §6.4.8 列了教师可编辑「难度」，但未定义取值范围。
- **评分并列的打破规则**：按章节顺序、按 id 还是按名称。必须确定，否则同输入不同输出。
- **权重是否按课程可配置**，配置存哪（SQLite 课程表 / 环境变量 / 请求参数）。
- **推荐条数上限与分页方式**。
- **目标导向路径是否纳入**（D-07）。
- **性能预算**：S2 表 6.7 给了构图 ≤50 秒、问答 ≤15 秒，路径推荐未给预算。
- **API 路径与 DTO**：按 ADR-004 先在 `src/contracts/` 定稿后回填。

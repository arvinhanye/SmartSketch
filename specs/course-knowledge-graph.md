# 功能规格：课程知识图谱 MVP

- **状态**：DRAFT（「前置关系成环处理」与枚举取值已由 A02 签收，见 ADR-009）。**关系 HTTP 路由已实现**：`POST /api/v1/courses/{cid}/relations` 与 `PATCH`/`DELETE /api/v1/courses/{cid}/relations/{rid}` 按契约落地（ADR-071，验收与证据见 `docs/archive/tasks-2026-09.md` 的 F06-API 小节）；成环处理验收 DAG-1、DAG-6、DAG-7、DAG-9 由它覆盖。
- **负责人**：产品 / 后端 / 前端共同维护
- **关联任务**：M1-01 ~ M1-05；验收 7 的抽取质量指标由 K01（口径与材料）、K02（计算与报告）落实（REQ-01）

## 用户故事

作为教师，我能为一个课程上传资料并得到可审核的草稿知识图谱；作为学生，我能只查看已发布图谱，并据此理解学习顺序与每条知识的来源。

## 数据与规则

- 节点至少含：`id`、`course_id`、`name`、`definition`、`confidence`、`status`、`source_refs`。
- 关系至少含：`id`、`course_id`、`type`、`from_id`、`to_id`、`confidence`、`status`、`source`、`source_refs`。`status` 与节点共用 `draft | low_confidence | approved | rejected`，`source ∈ {ai, manual}`；下文成环处理依赖这两个字段。
- `type ∈ {CONTAINS, PREREQUISITE, RELATED_TO, EXAMPLE_OF}`。
- `PREREQUISITE` 语义为 `from_id` 是学习 `to_id` 的前置条件，且同一课程内不得成环。
- 草稿仅教师可编辑；学生 API 只返回已发布版本。
- 所有端点前缀 `/api/v1`（`/health` 除外）；枚举取值与大小写以 `docs/architecture.md`「API 前缀与 wire 枚举」为准，本规格不另列一份。

### 前置关系成环处理（A02 / ADR-009）

**参与环检测的边**：同一课程草稿中 `type = PREREQUISITE` 且 `status ≠ rejected` 的边。

**可被自动降级的边**：`source = ai` 且 `status ∈ {draft, low_confidence}`，即未经教师确认的 AI 边。`source = manual` 或 `status = approved` 的边视为教师已确认，自动流程**永不**改动它们。

人工编辑与自动候选按来源区分处理，二者不可混用：

| 来源 | 触发路径 | 处理 | 结果 |
| --- | --- | --- | --- |
| **人工编辑** | 新建关系（`POST /api/v1/courses/{cid}/relations`）；改关系类型为 `PREREQUISITE`、改端点、反转方向、把 `rejected` 恢复为有效（`PATCH .../relations/{rid}`）；合并知识点后重接边（`POST .../kp/merge`）；`from_id = to_id` 的自环 | 写入前检测；成环则整个操作不写入 | 409 `CYCLE_DETECTED`，`details.cycle` 为首尾相同的节点 ID 链。**不自动修复，不降级任何边**，由教师自行决定改哪条 |
| **自动候选** | worker `persisting` 阶段写入草稿前 | 按下方降级算法逐环消解 | 任务照常进入 `awaiting_review`；被降级的边进入审核队列「低置信度关系」 |
| **自动候选，但环上没有可降级边** | 同上 | 不降级已确认边 | 任务 `failed`，`error.code = CYCLE_DETECTED`，带 `details.cycle`。只可能在草稿已违反不变量时出现 |
| **发布** | `POST .../publish` | 发布前全图复检 | 409 `PUBLISH_BLOCKED`，`details.reasons` 含环路；不产生版本 |

**降级算法**（自动候选专用，结果必须可复现）：

1. 自动候选中的自环（`from_id = to_id`）在抽取规则校验阶段直接删除并记日志（S2「删除自环」），不进入本算法。
2. 把本批候选与草稿中现有的参与边合成一张图，按边 `id` 升序遍历邻接做 DFS 找环。
3. 找到环后，在环上的可降级边里选 `confidence` 最低者；并列时取 `id` 字典序最小者。
4. 把该边 `type` 改为 `RELATED_TO`、`status` 改为 `low_confidence`，保留 `from_id`、`to_id`、`confidence`、`source_refs`。
5. 重复 2～4 直到无环，再写入草稿。每轮只降级一条，不承诺全局降级条数最少。

教师把降级边改回 `PREREQUISITE` 属于人工编辑，走上表第一行：环仍在则 409，环已被其他修改打破则允许。

**成环处理验收**（独立编号，不占用下方主验收序号）：

- 成功路径
  - **DAG-1** 已有有效边 B→C、C→A，教师新建 A→B → 409 `CYCLE_DETECTED`，`details.cycle` 为 `[A, B, C, A]` 的某个旋转；草稿无任何变化。
  - **DAG-2** 自动抽取产出 A→B（0.9）、B→C（0.8）、C→A（0.4），均为 `ai`/`draft` → C→A 变为 `RELATED_TO` + `low_confidence`，另两条保持 `PREREQUISITE`；任务到 `awaiting_review`，审核队列出现 C→A。
- 边界路径
  - **DAG-3** 环上可降级边置信度并列 → 降级 `id` 字典序最小者；同一输入重跑，降级结果完全相同。
  - **DAG-4** 教师已确认 A→B、B→C（`manual` 或 `approved`），自动候选 C→A 置信度 0.95 → 仍降级 C→A；已确认边不变。
  - **DAG-5** 一批候选含两个环（共享边或互相独立）→ 逐环消解直到无环；任务不失败。
  - **DAG-6** 教师把 DAG-2 中被降级的 C→A 改回 `PREREQUISITE`：A→B、B→C 仍有效时 409；教师先把 B→C 置为 `rejected` 后再改则允许。
  - **DAG-7** `status = rejected` 的 `PREREQUISITE` 边不参与环检测；把它恢复为有效且会成环 → 409。
  - **DAG-8** 已有 A→B、B→C，教师合并 A 与 C → 合并后形成 M→B→M，409，合并不生效。
  - **DAG-9** 自动候选自环 A→A → 规则校验阶段删除，不降级、不使任务失败；教师新建自环 A→A → 409，`details.cycle = [A, A]`。
- 失败路径
  - **DAG-10** `persisting` 时草稿中已存在一个全由已确认边组成的环 → 任务 `failed`，`error.code = CYCLE_DETECTED` 并带环路；不静默降级已确认边。
  - **DAG-11** 发布时图中含环（任意来源）→ 409 `PUBLISH_BLOCKED`，不产生新版本，学生仍读旧版本。

## 验收条件

1. 支持 PDF、DOCX、TXT、Markdown 上传；不支持格式返回明确错误代码。
2. 每次上传返回任务 ID；任务按 `queued → parsing → extracting → merging → persisting → awaiting_review → completed` 转换。处理阶段（直到 `awaiting_review`、`failed` 或 `cancelled`）可通过 SSE 观察；`awaiting_review` 表示处理完成，SSE 在此关流；`completed` 由教师发布触发，通过任务查询 `GET /api/v1/tasks/{tid}` 或课程发布状态观察，不经已有 SSE 连接送达；`failed` 只能从 `parsing`～`persisting` 转入，`cancelled` 只能从 `queued`～`merging` 转入。终态为 `completed`、`failed`、`cancelled`。转换表、取消协议、部分失败与重连见 `specs/task-processing.md`（A03 / ADR-010）。
3. 图谱查询、编辑和学生浏览均按 `course_id` 隔离。
4. 人工新增/修改前置关系形成环时操作被拒绝，并返回导致冲突的节点/关系信息；自动候选成环按上方「前置关系成环处理」降级，不拒绝整个任务。
5. 2D 图谱具备缩放、拖拽、节点详情、关系图例/筛选；节点详情展示至少一个来源。来源可点开查看资料文件名（`SourceRef.document_name`，只取同课资料，缺失时显示「资料不可用」）、页码或章节与原文片段（ADR-085）。
6. 教师发布后学生可读取该版本；未发布草稿不可由学生读取。
7. **抽取质量（赛题「技术要求与指标（一）」硬指标，REQ-01）**：
   - **基准材料**：一门完整课程中的一章。使用自编材料，或许可允许使用的开源教材（赛题第 7 节的版权要求）；真实课程资料不进仓库。具体用哪门课由 D-01 决定（已定：自编「数据结构 第3章 栈与队列」，`evaluation/fixtures/synthetic.json`，ADR-026）。2026-09-26 首次真实模型实测（DeepSeek `deepseek-flash`，简化融合）：AI 实体 74 个，人工全量判定实体 74/74、关系 61/63，三项达标；完整融合接入后须重跑，见 `evaluation/reports/extraction-accuracy.md`。
   - **实体数**：该章资料处理到 `awaiting_review` 后，草稿中 `source = ai` 的知识点节点（融合去重后）不少于 20 个；恰为 20 个视为达标。
   - **准确率**：人工抽样中判定正确的比例不低于 70%，恰为 70% 视为达标。实体和关系分别计算，两项都须达标（赛题没有区分，按较严的理解执行；D-15，ArvinHan 2026-09-24 确认）。判定标准和抽样方法（固定随机种子，写明样本量或全量检查）写入 `evaluation/README.md`；报告逐条列出被抽样的项和判定结果。
   - **判定对象**：只统计真实模型的输出，D-02 签收后执行，付费调用须另行确认；fake 模型的结果不能用来证明达标。提示词迭代所用材料与最终判定材料应当不同，相同时须在报告中注明。
   - **报告内容**：列出错误类型和改进方向（赛题允许存在冗余和错误，但要求说明改进方向）。该报告即参赛材料中的「知识抽取准确率的测试报告」。
   - **失败路径**：实体数少于 20 或任一准确率低于 70% 时，报告如实写「未达标」及差距，不得通过调整样本或判定标准凑数。

## 教师编辑工作区视口（2026-10-08）
- 仅教师图谱编辑页使用有限视口高度；长详情、编辑、关系与新建内容在左侧面板内部滚动，不撑高画布。关闭面板后，画布高度与小地图/缩放工具位置保持稳定。
- 搜索、关系筛选、布局切换和清空以紧凑横栏展示；高级筛选浮层不占据画布高度。全部筛选能力与草稿数据保持。
- 桌面左面板宽度默认360px，最小280px、最大640px且画布至少360px；拖动分隔条或用左右方向键、Home/End调整。窗口变窄时自动限制；手机保留上下排列与内部滚动。
- 保留所有编辑字段、未保存修改守卫、选择与草稿发布边界，不修改学生页面或后端。

图谱右下角的小地图、放大、缩小和适应画布按钮均带原生title说明（教师/学生）；鼠标停留后由浏览器显示，具体延迟遵循浏览器设置。小地图说明随展开状态更新；无按钮行为或图谱数据变化。

教师图谱编辑页的搜索栏、左侧详情/编辑面板和画布以独立圆角卡片排列；搜索框含图标，布局模式使用可键盘操作的分段选择，工具栏右侧提供唯一“新建知识点”入口。左侧保留详情、编辑知识点、编辑关系三个页签；原有新建表单、来源约束、字段和保存守卫保持，窄屏页签不固定以免覆盖关闭按钮。

## 图谱工作区交互约定（2026-10-08 复审补充）

仅前端交互与排版约定；不改接口、数据与权限。

- **面板选择与画布同步**：教师通过“选择知识点”下拉或详情中的关联知识点切换选中时，画布同时聚焦到该节点（与搜索定位一致）；有未保存修改时先确认，取消则画布与详情都不动。
- **关系编辑默认起点**：已选中知识点时进入“编辑关系”，该知识点直接作为起点（可在图上或下拉里改）；未选中则起点为空。此后在图上点击第一个节点是终点。
- **小地图稳定**：切换层次/力导向布局或章节位置重算后，小地图始终可见且与展开/收起开关一致（G6 小地图插件销毁时会摘掉容器，每次重建画布换用新容器）。
- **窄屏学生图谱**：收起的覆盖式说明面板不参与页面高度，页面不得出现画布下方的大片空白滚动区。
- **演示模式横幅**：学生图谱舞台高度扣除横幅占位，小地图、缩放、计数条始终落在视口内。
- **教师标题行**：“返回课程”并入标题行；画布提示与键盘选择器合为一行，把竖向空间还给画布。

## 教师图谱首屏总览与径向布局（2026-10-08，用户确认）

仅教师图谱编辑页；学生图谱页的首屏（可读缩放聚焦入口节点、章节分区布局）不变。

- **首屏总览**：打开教师图谱时先把整张（可见）图适应进视口，而不是放大到可读缩放聚焦根节点。整组适应的上、左留白收紧（教师页没有顶部浮层），右侧与底部仍避开缩放工具和小地图。“适应画布”按钮与之一致。
- **定位到知识点**：下拉选择、搜索、详情关联链接定位到某个知识点时，若当前缩放低于可读缩放（0.9），先放大到可读缩放再居中，避免只看到一个看不清的小点。有未保存修改时仍先确认。
- **布局选项**：教师工具栏为“层次 | 径向 | 力导向”。径向布局：先修/包含关系按最长路径分层，每个节点取上一层的一个父节点形成生成树，根在圆心（多个根时排第一圈），子树按叶子数占连续扇区，横向拉伸 1.5 倍以适配宽画布；不属于生成树的边照常画（直线），不参与摆位；同输入同输出。
- **默认选择**：节点 ≥ 24 且层次布局宽高比 > 3（单章大树被拉成长条）时默认径向，否则默认层次；教师手动选择后不再被自动改动。径向仅是“怎么摆”，不改变任何关系、方向语义或数据；前置关系方向在径向下以箭头表达。
- **已知限制**：画布缩放下限 0.2，极窄画布（手机）上总览可能略有裁切，可用“适应画布”或缩放查看。

## 教师图谱：节点类型图例与总览标签提示（2026-10-09，用户确认）

仅前端交互；不改接口、数据与权限；学生图谱页的图例与首屏不变。

- **节点类型图例**：教师图谱画布上方一行显示五类知识点（概念/定理/公式/方法/例题）的单字标记、名称与个数；个数取整张草稿图，不随筛选变化。点击某一类即隐藏/显示该类（与工具栏“筛选”里的知识点类型是同一份状态），有隐藏时出现“恢复全部类型”。按钮带可访问名称（含个数与当前状态）。

- **放大到可读大小**：画布右下角工具组新增按钮（教师与学生共用的画布控件）：缩放低于可读缩放时放大到 0.9，以视口中心为准；已经够大则不动。
- **径向布局**横向拉伸由 1.5 调为 1.9，更好地利用宽画布（约 1.9:1）；不改变节点间距下限（≥ 36px）。

## 悬停更新与停留阈值（GRAPH-HOVER-01，2026-11-05）

- 指针在同一节点停留 120ms 后才应用既有强淡化；不足阈值即离开时，不发出淡化或恢复写入。tooltip 仍从进入节点时按原 300ms 计时。
- 只把相对上次成功应用确有变化的元素状态交给 G6；状态名称、顺序、颜色与预览节点保护不变。首次强淡化和彻底退出可能仍改变全图状态，不承诺它们只更新少量元素。
- 保留 60ms 离开防闪；节点间转换取消待恢复，连续空白移动不延后恢复期限。节点离开、画布空白移动、进入边、离开画布容器均取消未生效候选。
- 状态写入复用画布串行队列。预览/学习进度更新、标签/缩放重绘后同步差分缓存；节点移除与销毁不得留下延迟淡化。
- 验收：差分、120ms/60ms、重绘、预览、销毁与异步写入回归；1440×900 演示图普通/预览各 10 次进出实测，分别报告同步调用与长任务，不能以单测代替性能验收。

## 图谱画布键盘约定（UI-QA-01，2026-10-09）

图谱画布（G6 创建的 canvas）是指针交互层，不是键盘停靠点；键盘与读屏用户通过搜索、章节菜单、列表视图和详情完成同样的操作。画布及其子 canvas 不得带正的 `tabindex`，也不进入 Tab 顺序：页面上的第一个 Tab 停靠点是顶栏/导航链接，而不是不可见的 canvas。画布重建（换布局、换位置、重试）后同样成立。

## 教师图谱详情：来源行与标题焦点（UI-BATCH2-01，2026-10-09）

教师页左侧详情的每条来源是一个左对齐的整块按钮，“文件名：位置”自然换行，不被居中挤成碎片；程序聚焦到知识点标题（用于读屏从名称开始播报）时不画整行焦点框，避免盖住关闭按钮。关于“离开页面前提示未保存修改”：路由内离开（确认框）与关闭标签页/刷新（`beforeunload`）自 H14 起已实现，本批只补回归测试。

## 图谱查找、快捷键与视图记忆（UI-GRAPH-FIND-01，2026-11-10，用户确认）

仅前端交互；不改接口、契约、数据与权限。适用于学生图谱页与教师图谱编辑页，另有说明的除外。

### 搜索：高亮而不是隐藏

- 输入关键字不再把不匹配的知识点从画布上移除。命中的知识点带 `match` 状态（靛紫外环、标签加粗）；没有预览/选中时其余知识点标准淡化（`dimmed`），关系线保留。关键字没有任何命中时不淡化，按回车给出“未找到”提示。
- 匹配范围：名称与别名（契约 `aliases`）；规范化规则不变（忽略大小写、全半角与首尾空白）。排序：名称完全一致 > 名称以关键字开头 > 名称包含 > 别名完全一致 > 别名包含；同级按图中原有顺序。被类型、审核状态、章节筛选隐藏的知识点不参与匹配。
- 学生页搜索框下方显示候选（最多 8 条，含章节与类型；经别名命中时注明别名），↑/↓ 移动、回车选定、Esc 收起；搜索框右侧显示“第几个 / 共几个”与上一个、下一个按钮。回车依次定位下一个命中，Shift+回车定位上一个，到末尾回到第一个。定位仍是“进入预览”（列表视图直接打开详情）。
- 学生页列表视图仍按关键字只列命中的卡片（列表没有“淡化”语义）。
- 教师页沿用工具栏搜索框：回车依次定位下一个命中并显示“第几个 / 共几个”；选中仍经过“未保存修改”确认。
- 搜索定位时若当前缩放低于可读缩放（0.9），先放大到可读缩放再居中。详情就绪后通常把焦点移到标题；焦点在搜索框里时不移动，保证可以连续按回车。
- `filterGraph` 纯函数的既有语义不变（按名称隐藏）；页面通过 `useGraphFilters` 的 `search: 'highlight'` 选项启用新行为。

### 快捷键

- `/` 聚焦搜索框；`F` 适应画布；`+`（或 `=`）放大；`-` 缩小。只在图谱视图、画布就绪时生效。
- 焦点在输入框、文本域、下拉框、可编辑区域内，或同时按下 Ctrl/⌘/Alt，或正在输入法组合时不触发。
- 画布仍不是 Tab 停靠点（见“图谱画布键盘约定”）；快捷键是效率路径，不替代搜索、章节菜单与列表视图。对应按钮的悬停说明里写出按键。

### 视图记忆

- 学生页把当前视图写进地址（`router.replace`，不产生历史记录）：`kp` 已打开详情的知识点、`q` 搜索关键字、`ch` 定位的章节、`rel` 被隐藏的关系类型、`type` 被隐藏的知识点类型（逗号分隔）、`view=cards` 列表视图。缺省值不写。重新打开同一地址恢复这些状态；不认识的值忽略。
- 用户自己改选知识点后，地址里来自问答链接的 `v` 一并移除，不再重复出现“回答基于第 N 版”的提示。
- 镜头位置（平移、缩放）不写进地址：恢复 `kp` 后镜头聚焦到该知识点。
- 学生页与教师页的面板宽度记在本浏览器（`localStorage`，只存一个数字）；存储不可用时照常工作，只是不记忆。

### 验收

- 成功：输入关键字后画布节点数不变，命中节点带 `match`、其余带 `dimmed`；回车与 Shift+回车在命中之间循环；别名可命中；`/`、`F`、`+`、`-` 生效；选中、筛选、章节、视图写入地址并可由地址恢复；面板宽度刷新后保留。
- 边界：关键字为空或只有空白等于不搜索；已有预览/选中时命中仍带 `match`，淡化由预览/选中决定；地址里的知识点、章节不存在时忽略且不报错；焦点在输入框时按 `/`、`F` 只输入字符。
- 失败：没有命中时回车给出提示且不改变当前预览/选中；`localStorage` 抛异常时页面不报错。

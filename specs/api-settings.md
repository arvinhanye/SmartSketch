# 本机 API 设置（2026-09-30）

用户要求：教师侧栏“我的课程”下方新增 API 设置，填写 DeepSeek 聊天/抽取和通义 text-embedding-v4 配置，避免手改环境文件。配置为本机全局配置，不支持多租户。

GET/PUT `/api/v1/api-settings` 及 POST `/api/v1/api-settings/test` 仅教师可用，沿用 Bearer 登录鉴权。读取仅返回密钥已配置标记；空密钥保留已有值，禁止回显密钥和服务商原始错误正文。配置原子保存到用户应用数据目录，API 与 worker 重启后读取同一配置。发行版允许通过 SMARTSKETCH_API_CONFIG 指定本地设置文件，此为用户明确要求的环境变量规则例外。

界面显示已保存模式及当前生效模式。保存须明确提示重启；更换向量空间拒绝直接保存，需先停止服务、备份数据库并执行已有 reembed.py 迁移，失败保留原空间。通义默认 1024 维；连通性测试只发单个短请求。

验证仅配置保存/密钥隐藏/非法地址拒绝、教师与学生权限、前端类型检查及构建、单次接口连接测试；按用户要求不跑全量 verify.sh。

POST `/api/v1/api-settings/models` 的 `list_path` 是模型发现请求参数（默认为 `/models`），应在持久配置校验前分离；不得添加到配置白名单或写入设置文件。省略该参数时保留既有发现行为。

2026-10-01 回退确认：演示模式仍受支持，不强制保存为 live/online，也不按配置完备性拦截教师页面、问答或资料任务。向量目标模型/维度可选择并保存；首次保存也不自动启用，不更改现有模型/维度和数据库空间。保留既有向量空间启动校验。取消本轮新增的 /status、课程智能状态和重新处理端点。

# 功能规格：教师审核与图谱发布

- **状态**：DRAFT（桩，并发与快照策略未定稿）
- **负责人**：产品 / 后端 / 前端共同维护
- **关联任务**：M1-05（拆分方式见 **D-05**）

## 用户故事

作为教师，我能在学生看不到的草稿上修正 AI 生成的图谱，确认无误后发布；发布后再修改时学生仍看旧版本，直到我重新发布。作为学生，我任何时候看到的都是一个完整、已被教师确认过的版本。

## 数据与规则

### 三态流转

| 状态 | 含义 | 学生可见性 |
| --- | --- | --- |
| **草稿** | AI 生成或教师修改中 | 不可见 |
| **已发布** | 教师确认后发布；**发布时自动保存快照** | 可见 |
| **修订中** | 已发布课程再次被修改 | **仍看上一发布版本**，教师重新发布后更新 |

```text
草稿 ──发布──→ 已发布 ──教师再次修改──→ 修订中 ──重新发布──→ 已发布
                  ↑                                      │
                  └──────────── 回滚到历史快照 ───────────┘
```

关键不变量：**只要曾经发布过，学生就始终能读到某个完整版本**。「修订中」不得让学生看到半成品，也不得让学生读不到任何东西。

### 节点加锁

**教师手动修改过的节点加锁，后续自动流程不覆盖。** 这是人机协同的核心约束：重新上传资料、重跑抽取、重跑融合，都不得改写加锁节点。加锁是自动流程的边界，不是并发锁。

### 审核队列

列出三类待处理项，支持一键通过 / 拒绝 / 合并：

- 低置信度关系
- 疑似重复知识点
- 孤立知识点

### 一致性

- 所有修改经后端统一接口在**事务中**写入，同步更新向量与索引。
- 修改记录写入日志（谁、何时、改了什么）。
- 新增或修改 `PREREQUISITE` 时**实时做环检测**，成环则拒绝并提示环路（AGENTS.md §4、M1-04）。

## 验收条件

### 成功路径

1. 草稿 → 已发布：学生可读该版本，内容与教师发布时一致。
2. 已发布 → 教师修改 → 修订中：**学生仍读到上一发布版本**，读不到修改内容。
3. 修订中 → 重新发布：学生读到新版本，**旧快照仍然保留**。
4. 回滚到任一历史快照后，学生读到该快照的内容。
5. 教师手动改过的节点被加锁；重跑抽取或融合后，该节点内容不变。
6. 审核队列能列出低置信度关系、疑似重复、孤立节点三类，且通过/拒绝/合并后队列相应更新。

### 边界路径

7. 课程从未发布过，学生请求 → 返回明确的「尚未发布」状态。**不是 500，不是空图谱**——空图谱会被前端渲染成「这门课没有知识点」，语义完全不同。
8. 审核队列为空 → 可以直接发布，不得强制要求处理项。
9. 回滚到当前正在生效的版本 → 行为需确定（幂等还是产生新版本号，见「待细化」），不得报错。
10. 两名教师同时编辑同一节点 → 冲突策略见「待细化」；**至少不得静默覆盖**，后写者必须知道自己覆盖了什么。
11. 加锁节点在教师**主动解锁**后可被自动流程更新；解锁必须是显式动作。
12. 发布一个与上一版本完全相同的图谱 → 行为需确定（是否产生新快照），不得报错。

### 失败路径

13. 学生调用教师端的编辑或发布接口 → 拒绝，返回明确错误码。
14. 发布时图谱含 `PREREQUISITE` 环 → **拒绝发布**并指出环上的节点/关系；不得发布出一个有环的版本。
15. 跨课程 `course_id`（教师尝试编辑非自己课程的节点）→ 拒绝。
16. 快照写入失败 → **整个发布失败**，状态回到发布前；不得停在「已发布但无快照」的半状态。
17. 事务中途失败（如向量索引更新失败）→ 图谱数据与索引不得处于不一致状态；失败必须留下可重试的记录（ADR-002 跨存储编排要求）。
18. 回滚到不存在的快照 id → 拒绝并指出。

## 待细化

- **快照的存储形态**：全量副本还是增量差分；保留多少份；存 SQLite 还是 Neo4j。S2 只说「发布时保存快照，可回滚到任一历史版本」，没定实现。
- **加锁的粒度**：整个节点、单个字段，还是节点加其关系？教师只改了定义，是否连带锁住难度字段？
- **解锁方式**：教师显式解锁，还是有过期策略。
- **并发编辑冲突策略**：乐观锁（版本号比对后拒绝）还是后写覆盖加日志。D-05 决定 M1-05 怎么拆之后再定。
- **回滚是否产生新版本号**：影响版本历史的可读性。
- **「修订中」是否允许多个并存**：多名教师各自修订同一课程时的语义。
- **审核队列的排序与分页**：按置信度、按章节还是按类型。
- **低置信度阈值**：`specs/course-knowledge-graph.md` 也把它列为待细化，两处需同批定稿。
- **API 路径与 DTO**：按 ADR-004 先在 `src/contracts/` 定稿后回填。

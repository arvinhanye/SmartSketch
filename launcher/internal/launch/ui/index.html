1 · 配置课程向量服务（系统默认）

向量模型用于在课程资料里查找与问题相关的内容。这里填写的是系统默认，学生使用的也是它；教师登录后，可以在「模型 API 设置」里为自己的课程单独设置向量服务。

教师和学生的生成模型 API（例如 DeepSeek）在登录后各自设置，不在这里填写。这是两项不同的配置。

选择预设会自动填写下面三项。也可以选「其他服务商」，手动填写任何兼容 OpenAI 接口的向量服务。

服务商提供的接口地址，通常以 /v1 结尾。用「阿里云百炼」预设时已为你填好。

必须与服务商文档里的模型名称完全一致，例如 text-embedding-v4。

模型输出的向量长度。默认的 1024 只适用于 text-embedding-v4，不是所有模型通用，换模型前请先查服务商文档。建立索引后不能更改。

在服务商控制台创建的密钥。只保存在本机，页面不会显示它；这里也不会测试它是否有效。

2 · 创建首位教师

3–32 位，只能用小写英文字母、数字和 _ . - 。之后用它登录。

请自己记住这个密码。

再输入一次，两次必须一致。

默认 8080。如果被其他程序占用，换成 1024–65535 之间的空闲端口。

仅检查配置格式，不测试供应商连接，不验证额度，也不会自动发出收费 API 请求。

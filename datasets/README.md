# 标注集

归 Data/AI Agent。评测用的标注数据放这里。**本目录的核心规则是区分两类东西**：

| | 可入库 | 不可入库 |
| --- | --- | --- |
| 内容 | 标注元数据：知识点名、关系三元组、问答对的期望答案要点、来源定位（文档 id + 页码/章节） | 原始课程资料：教材、课件、教案的 PDF/DOCX/PPTX 原文与扫描件 |
| 位置 | `datasets/<课程>/*.jsonl`、`*.yaml` | `datasets/raw/`（已在 `.gitignore` 忽略）、`storage/`、`uploads/` |
| 理由 | 体量小、可复核、不含受版权保护的正文 | **教材受版权保护**，提交即侵权；也可能含未脱敏的个人信息 |

来源定位用**引用**而不是**原文**：记 `{document_id, page, section}`，不要把整段课文复制进标注文件。需要少量正文才能判定时，截取不超过一句并注明出处。

## 布局

```text
datasets/
├── README.md
├── raw/            # 原始资料，内容不入库，仅保留目录
└── <课程标识>/     # 该课程的标注集，可入库
```

## 格式约定

- 一行一条记录的 JSONL；字段名与 `src/contracts/` 的契约一致，不另立一套（ADR-004）。
- 每条标注带 `course_id`，与课程隔离规则一致。
- 关系标注的 `type` 只允许 `CONTAINS`、`PREREQUISITE`、`RELATED_TO`、`EXAMPLE_OF`。
- 标注集本身要版本化：换内容就改文件名里的版本，不要原地覆盖——否则历史评测结果不可比。

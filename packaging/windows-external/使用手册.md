# 智绘学途 Windows 轻量版使用手册

本 ZIP 包含完整的软件代码、已构建前端、演示资料、启动与停止脚本，**不包含 Python、Java、Neo4j 或它们的安装程序**。适用 Windows 10/11 x64。设置运行环境时需要网络；设置完成后，默认演示模式不调用外部大模型。

## 一、安装运行环境

1. 安装 **Python 3.12（含 pip）**。可从 <https://www.python.org/downloads/> 下载 Windows x64 安装程序。安装后在 PowerShell 运行 `py -3.12 --version`，应显示 `Python 3.12.x`。
2. 安装 **Java 17 x64**，例如 Temurin 17：<https://adoptium.net/temurin/releases/?version=17>。将 `JAVA_HOME` 环境变量设为 Java 根目录（该目录内应有 `bin\java.exe` 和 `release`），例如 `C:\Program Files\Eclipse Adoptium\jre-17...`。
3. 下载并解压 **Neo4j Community 5.26.31 Windows ZIP**：<https://neo4j.com/deployment-center/>。将 `NEO4J_HOME` 环境变量设为解压后的根目录（该目录内应有 `lib`、`labs` 和 `plugins`）。把 `labs\apoc-5.26.31-core.jar` 复制到 `plugins`。该 JAR 随 Neo4j ZIP 提供，无需另行下载 APOC。

环境变量可在 Windows「编辑系统环境变量」→「环境变量」→「用户变量」中设置。设置后重新打开 PowerShell；若从文件管理器双击启动仍提示找不到变量，注销并重新登录 Windows。

## 二、安装本软件的 Python 依赖

将本 ZIP **完整解压**到一个可写目录。在该目录打开 PowerShell，运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

这一步需要联网下载 Python 依赖。无需安装 Node.js、Bash、WSL 或 Docker。日后重新启动不需要重复安装依赖。

## 三、启动和停止

双击 `启动智绘学途.cmd`。脚本会检查上述环境、启动本机 Neo4j，运行迁移，启动 API 和 worker，导入演示课程；全部就绪后打开默认浏览器 <http://localhost:18080/>。首次导入可能需要几分钟。请不要直接在 ZIP 预览窗口运行脚本。

结束使用时双击 `停止智绘学途.cmd`。数据不会删除；下次启动沿用课程和进度。Neo4j 的 HTTP、Bolt 及应用网页分别使用本机端口 17474、17687、18080。

| 角色 | 账号 | 初次创建时的密码 |
| --- | --- | --- |
| 教师 | `demo_teacher` | `smartsketch-demo` |
| 学生 | `demo_student`、`demo_student2` | `smartsketch-demo` |

重复启动不会重置已有账号密码。

## 数据与故障排查

软件数据、随机生成的数据库口令、日志在 `%LOCALAPPDATA%\SmartSketch-External`。它与“内置运行环境版”的数据目录分开。请勿公开其中的 `portable-config.json`；备份前先停止软件。

- 提示缺 Python：确认 `.venv\Scripts\python.exe` 存在，且创建虚拟环境用的是 Python 3.12。
- 提示缺依赖：重新运行第二节的 pip 命令。
- 提示缺 Java、Neo4j 或 APOC：核对 `JAVA_HOME`、`NEO4J_HOME` 及 `plugins\apoc-5.26.31-core.jar`。
- 提示端口被占用：先停止另一份智绘学途或占用 17474、17687、18080 的程序。
- 提示“未找到 NEO4J_HOME 指向的 Neo4j 5.26.31”：检查 `launcher\local-runtime.json` 的 `neo4j` 路径是否为纯 ASCII 路径且目录内含 `lib` 与 `plugins`。
- 日志里出现 `is not a directory. Only directories can be registered to be monitored`：Neo4j 运行时或数据目录路径含中文/特殊字符，换到纯英文路径。
- 启动后没有浏览器页面：查看 `%LOCALAPPDATA%\SmartSketch-External\logs` 的报错日志。

版本来源：`arvinhanye/SmartSketch` 的 `codex/login-visual-refresh` 分支，提交 `89c885b`。ZIP 的 SHA-256 见同名 `.zip.sha256` 文件。

## 本机运行环境说明（内置运行环境版）

本机直接使用随包内置的运行时，不依赖系统全局环境变量。相关路径记录在 [launcher/local-runtime.json](launcher/local-runtime.json)：

- `python`：内置 Python 3.12，已装齐 `requirements.txt` 依赖；
- `java`：Java 17（`JAVA_HOME` 指向的目录内必须有 `release` 文件，启动脚本会校验 `JAVA_VERSION="17.`）；
- `neo4j`：Neo4j Community 5.26.31，`plugins\apoc-5.26.31-core.jar` 必须存在。

**运行时路径必须全部是纯 ASCII 字符。** 路径含中文时 Neo4j 会把目录名转义成 `\uXXXX` 并报
`… is not a directory. Only directories can be registered to be monitored.`，服务无法启动。
因此内置运行时建议放在 `%LOCALAPPDATA%\SmartSketch-Runtime\`（本机即为该位置），不要放在含中文的目录下。

API 密钥本机保存在 `launcher\api-settings.json`（启动脚本设置 `SMARTSKETCH_API_CONFIG` 指向它），
这样更换数据目录或在不同沙箱环境中运行都不会丢配置；密钥使用 Windows 当前用户加密，文件请勿外传。

## 页面配置 API
教师登录后，点击左侧“我的课程”下方的“API 设置”。密钥留空保留旧值；密钥使用 Windows 当前用户加密。保存后重启软件生效。更换向量模型须先停机备份并运行 app/scripts/reembed.py，页面会阻止未迁移的向量切换。
本机运行环境路径记录在 launcher/local-runtime.json。
模型名不再预置：先填服务商地址与 API Key，再点“获取模型列表”，从识别结果里选择（也可手动填写模型名）；
两块接口（大模型、向量）各自独立测试，结果在各自的小窗口中显示往返延迟与成败。
